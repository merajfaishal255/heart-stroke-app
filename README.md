# ❤️ Heart Stroke Prediction App

A machine learning web application built with **Python** and **Streamlit** that predicts the likelihood of a heart stroke based on patient health details.

## 📋 Overview
This project uses a **Random Forest Classifier** to analyze health parameters (like age, glucose level, and BMI) and determine if a patient is at "High Risk" or "Low Risk" of a stroke. It is designed to demonstrate how AI can assist in healthcare risk assessment.

## 🚀 Features
* **Interactive Sidebar:** Easy-to-use input form for entering patient details.
* **Real-Time Prediction:** Instantly calculates risk upon clicking "Predict".
* **Machine Learning:** Uses the Random Forest algorithm for classification.
* **Health Metrics:** Considers key factors:
    * Age
    * Hypertension
    * Heart Disease History
    * Average Glucose Level
    * BMI (Body Mass Index)

## 🛠️ Tech Stack
* **Python** (Logic)
* **Streamlit** (Frontend Interface)
* **Pandas** (Data Handling)
* **Scikit-Learn** (Machine Learning Model)
